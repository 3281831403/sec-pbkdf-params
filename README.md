# 口令记录迁移器

迁移时把旧口令记录整表重算，结果所有老用户都登不进来，新参数也没真正生效：参数必须随哈希一起存储；验证必须使用记录里的参数而不是全局默认值；迭代次数低于策略下限必须拒绝并升级；盐必须唯一且长度足够；算法标识缺失必须拒绝；验证必须恒时比较；批量验证各记录独立。不变量：同一口令与同一记录两次验证结果相同；参数升级后旧记录仍可验证。
